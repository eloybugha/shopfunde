Häufige Fragen

Das Set im Küchenalltag

Enthält das 16-teilige Set wirklich acht Glasdosen?

Ja. Der Anbieter zählt acht Glasbehälter und acht passende Deckel. Auf dem Produktbild siehst du vier rechteckige und vier quadratische Dosen.

Warum sehe ich beim Auspacken zunächst nur vier Dosen?

Das Anbietervideo zeigt, dass die kleineren Behälter in den größeren liegen. Öffne die vier äußeren Dosen, um den Lieferumfang zu prüfen.

Kann der Deckel mit in die Mikrowelle?

Der Anbieter bezeichnet das Set als mikrowellengeeignet. Für den Deckel nennt die abgebildete Übersicht keine eigene Freigabe. Beachte vor dem Erwärmen die Kennzeichnung an Dose und Deckel.
